## 1. IndiaMART — create seller profile (highest B2B value)

### What it is
India’s largest B2B marketplace. Buyers post requirements; sellers get enquiries / buy leads. **Free company listing** is real; **paid** = more visibility / buy-leads.

### Official entry points
- Sell / register: https://seller.indiamart.com/  
- Help: https://help.indiamart.com/ (Selling on IndiaMART)  
- Support: customercare@indiamart.com · **+91-96-9696-9696**

IndiaMART’s own pitch: **free listing in ~3 steps**, no commission on free model; paid products (BuyLeads, Maximiser, etc.) are optional upsells.

### Step-by-step (desktop or app)

**Step 1 — Register**
1. Open https://seller.indiamart.com/  
2. Click **Join Now / Sell for free / Register**  
3. Enter **mobile** (+91-9982170555) → OTP  
4. Enter **email** → verify if asked  
5. Set password  

**Step 2 — Company profile**
1. Company name: **Silbar Security Services Pvt. Ltd.** (exact)  
2. Business type: **Service Provider** (not Manufacturer unless you manufacture)  
3. Primary category examples:  
   - Security Services  
   - Security Guard Services  
   - Facility Management Services  
   - CCTV / Surveillance Services  
4. Year of establishment: **2018**  
5. Number of employees: use **honest band** (if “7000+” is real staff+deployed, be ready to justify; better under-claim than get flagged)  
6. Address: **full NAP above**  
7. Website: https://www.silbarsecurity.in  
8. GSTIN: enter + upload GST cert when prompted  
9. Upload logo  

**Step 3 — Add products/services (critical)**
1. Go to **Products / Manage Products**  
2. Add each service from §0.4 as a **product/service card**  
3. For each:  
   - Clear title: “Security Guard Services in Delhi NCR | PSARA Licensed”  
   - Description with city + PSARA + ISO (truthful)  
   - Unit: “Contract / Per Month / Per Guard” as applicable  
   - Price: **“Ask Price”** or realistic range (avoid fake ₹1 prices)  
   - Photos: logo + service image  
4. Aim for **minimum 8–12 live services** before asking for ranking  

**Step 4 — Trust & completeness**
1. Complete **profile strength** bars (usually need ~80%+)  
2. Enable **mobile verification**, email, GST  
3. Add **IEC** only if export (usually N/A for pure domestic security)  
4. Set business hours & preferred contact mode (call + WhatsApp)  
5. Turn on **Lead Manager** notifications  

**Step 5 — Catalog URL**
- After publish, public URL looks like:  
  `https://www.indiamart.com/<your-slug>/`  
- Save URL → later put in Silbar site footer / sameAs if stable  

### Paid IndiaMART (optional, later)
| Product | When |
|---------|------|
| **BuyLeads** | You want to buy buyer requirements in “security guards / facility management” |
| **Maximiser / catalog ads** | After free profile is complete & you answer leads fast |
| Avoid | Paying on day 1 with empty catalog |

Sales will call aggressively. Script: *“Complete free listing first; revisit paid after 30 days.”*

### IndiaMART pitfalls
- Duplicate companies under slightly different names → merge/claim, don’t create second  
- Wrong category (e.g. listed as manufacturer)  
- Never-answer enquiries → ranking drops  
- Fake prices / stock photos only  
- GST mismatch with legal name  

### Silbar success metric (30 days)
- Profile live + GST verified  
- 10+ services  
- Response time &lt; 2 hours on enquiries  
- Public catalog URL saved

## 2. JustDial — free / paid business listing

### What it is
India’s mass **local discovery** directory (calls + app). Critical for “security agency near me / Delhi / Jaipur”.

### Official paths (UI changes often)
- Free listing (common paths used by JD):  
  - https://www.justdial.com/Free-Listing  
  - https://www.justdial.com/cms/business-listing  
  - JustDial app → **List your business** / **Advertise**  
- Business owner login: search “Justdial vendor login” / **JD Mart / Jd Pay** ecosystems vary by product  
- Support: often **88888-88888** (JustDial consumer/business helpline — confirm on site)

*(Note: JustDial web sometimes blocks scrapers/bots; use a normal browser or the mobile app.)*

### Step-by-step

**A. Search first (claim vs create)**
1. On JustDial, search: **“Silbar Security”** + Delhi / Jaipur  
2. If listing exists:  
   - Open → **Is this your business? / Claim**  
   - OTP on company phone / docs  
3. If **not** found → **Free Listing / Add business**

**B. Create listing**
1. Business name: **Silbar Security Services Pvt. Ltd.**  
2. Categories (pick 3–5 max, accurate):  
   - Security Services  
   - Security Guards  
   - Private Security Agencies  
   - Facility Management Services  
   - CCTV Services *(if you sell/install)*  
3. Address: exact HQ NAP  
4. Phone: **9982170555** (primary)  
5. Email, website  
6. Hours: Mon–Sat (match site)  
7. Photos: exterior + logo + team  
8. Year established, payment modes  
9. Submit  

**C. Verification**
- OTP on phone  
- Sometimes call verification  
- Sometimes document upload for “trusted” badge  
- PIN sent by post is rare now but possible for address  

**D. After approval**
1. Claim **owner dashboard**  
2. Add:  
   - Services menu  
   - Brochure PDF  
   - Offers (e.g. free security audit)  
   - WhatsApp button  
3. Request / collect **JustDial ratings** (real clients only)  
4. Enable **Enquiries** notifications  

### Paid JustDial (optional)
| Product | Role |
|---------|------|
| **Featured / Premium listing** | Top of category in city |
| **JD Pay / leads** | Pay-per-lead style packages (varies) |
| Rule | Free complete listing first → measure calls → then paid |

### JustDial pitfalls
- Multiple duplicate listings (Silbar / Silbar Security / Silbar Pvt Ltd) → claim & merge  
- Wrong city only (list **Delhi** primary; add other cities only if you have real ops + local number if required)  
- Competitors create fake listings with your number — monitor monthly  
- Category spam (20 categories) → less trust  

### Multi-city strategy
- **Primary:** New Delhi (HQ)  
- **Secondary cities** (Jaipur etc.): only if real branch / PSARA presence; same brand name, local address if real  
- Do **not** create 50 fake city listings

## 3. Sulekha — list your business

### What it is
Local services marketplace (home + business services). Stronger in some metros for service enquiries; weaker than IndiaMART for pure B2B security, still useful as a **citation**.

### Official
- https://www.sulekha.com/list-your-business  
- Often opens a **business dashboard** (SPA — use Chrome, allow JS)  
- Also: Sulekha app / “Register as service professional”

### Step-by-step

1. Open **List your business**  
2. Sign up with **mobile OTP** + email  
3. Select city: **Delhi** (primary)  
4. Category: **Security Services / Security Guards / Manpower** (closest match)  
5. Business name + NAP  
6. Service areas: NCR cities you actually cover  
7. Description (About block)  
8. Photos + logo  
9. Pricing: packages or “on request”  
10. Verify phone  
11. Complete profile %  

### After listing
- Respond to Sulekha leads fast (they decay)  
- Ask real clients for Sulekha reviews  
- Ignore pressure to buy packages until lead quality is clear  

### Sulekha pitfalls
- Treated like plumber/salon lead gen — filter tire-kickers  
- Category mismatch → zero leads  
- Incomplete profile not indexed well
